# 마비노기 모바일 염색 도우미

마비노기 모바일 게임의 염색 시스템을 도와주는 Windows 프로그램입니다.

## 주요 기능

- **색상 검출**: 화면 내 특정 색상을 실시간으로 검출
- **흑백 처리**: 지정 색상 외 영역을 흑백으로 표시하여 원하는 색상을 쉽게 찾기
- **HEX 코드 입력**: #000000 형식으로 정확한 색상 지정
- **3색 가이드라인**: 삼각형 가이드로 3개 색상 조합 위치 표시
- **오차율 설정**: 색상별 허용 오차 조절
- **단축키 지원**: 빠른 조작을 위한 다양한 단축키

## 시스템 요구사항

- Windows 10/11
- 관리자 권한 필요
- 마비노기 모바일 PC 클라이언트

## 설치 방법

### 방법 1: 실행 파일 다운로드
1. [Releases](../../releases) 페이지에서 최신 버전 다운로드
2. `MabinogiDyeHelper.exe` 실행 (관리자 권한)

### 방법 2: 소스에서 빌드
```bash
# 저장소 클론
git clone https://github.com/user/mabinogi-mobile-dye-helper.git
cd mabinogi-mobile-dye-helper

# 의존성 설치
pip install -r requirements.txt

# 실행
python main.py

# 또는 빌드
pyinstaller build.spec
```

## 사용 방법

### 기본 사용법
1. 마비노기 모바일을 먼저 실행합니다
2. 염색 도우미를 **관리자 권한**으로 실행합니다
3. "영역 설정" 버튼으로 검출할 영역을 지정합니다
4. 원하는 색상을 HEX 코드로 입력합니다 (예: #FF0000)
5. "시작" 버튼을 클릭합니다

### 3색 가이드 사용법
1. 게임 내 염색 팔레트에서 첫 번째 색상 위치에 커서를 놓고 `CTRL+4`
2. 두 번째 색상 위치에서 `CTRL+5`
3. 세 번째 색상 위치에서 `CTRL+6`
4. 삼각형 가이드가 화면에 표시됩니다
5. 초기화: `CTRL+7`

## 단축키

| 단축키 | 기능 |
|--------|------|
| `CTRL + 1,2,3` | 현재 커서 좌표 저장 |
| `ALT + 1,2,3` | 저장된 좌표로 커서 이동 |
| `CTRL + 4,5,6` | 삼각형 꼭지점 저장 |
| `CTRL + 7` | 삼각형 초기화 |
| `CTRL + 8` | 캡처 시작/중지 |
| `CTRL + 방향키` | 커서 픽셀 단위 이동 |

## 영역 선택기

- **좌클릭 드래그**: 크기 조절
- **우클릭 드래그**: 위치 이동
- 모서리를 드래그하여 크기 조절 가능

## 주의사항

- ⚠️ **#FFFFFF (리화)** 선택 시 막대기 색상 때문에 정상적으로 검출되지 않을 수 있습니다
- 프로그램이 동작하지 않으면 **관리자 권한**으로 실행했는지 확인하세요
- 영역이 마비노기 모바일 창 밖으로 나가면 동작하지 않습니다

## 문제 해결

### 프로그램이 실행되지 않음
- 관리자 권한으로 실행
- Windows 호환성 모드 설정 (Windows 8)

### 흑백 처리가 안됨
- 영역이 게임 창 안에 있는지 확인
- 게임이 최소화되어 있지 않은지 확인

### 단축키가 작동하지 않음
- 관리자 권한 확인
- 다른 프로그램과 단축키 충돌 확인
