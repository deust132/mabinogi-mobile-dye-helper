# 마비노기 염색 도우미 (Android)

## 기능
- 3개 색상 설정 및 검출
- 플로팅 버튼으로 화면 캡처
- 세로 가이드라인 3개 표시
- 검출된 색상 위치 점멸 표시

## 빌드 방법

### 필요 사항
- Android Studio (최신 버전)
- JDK 17 이상

### 빌드 순서
1. Android Studio에서 이 폴더 열기
2. Gradle Sync 완료 대기
3. Build > Build Bundle(s) / APK(s) > Build APK(s)
4. `app/build/outputs/apk/debug/app-debug.apk` 생성됨

## 사용법
1. 앱 설치 후 실행
2. "다른 앱 위에 표시" 권한 허용
3. 색상 버튼 클릭해서 찾을 색상 설정
4. "시작" 버튼 클릭
5. 화면 캡처 권한 허용
6. 플로팅 버튼 사용:
   - 📷 캡처 및 분석
   - 📋 가이드라인 표시/숨기기
   - ❌ 종료

## 단축키 (PC 버전과 비교)
| PC 버전 | 안드로이드 버전 |
|---------|----------------|
| CTRL+4,5,6 | 없음 (터치로 조작) |
| CTRL+7 | 없음 |
| CTRL+8 | 캡처 버튼 |

## 주의사항
- Android 10 이상에서 권한 제한이 있을 수 있음
- 일부 게임에서 오버레이 앱 사용 시 제한 가능
